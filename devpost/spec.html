DataTrail — Technical Blueprint

Deterministic client-side privacy intelligence engine rendering 4-stage data journeys with 100% verified verbatim quotations.

System Architecture & Component Flow

Architecture: Deterministic Policy Intelligence

DataTrail operates entirely client-side, eliminating external server dependencies and guaranteeing zero quote hallucinations:

  • Sentence & Clause Tokenization: Divides legal policies into individual claims while respecting abbreviations, section headers, and lists.
  • Category Matcher: Uses semantic keyword matrices to identify whether the policy collects Geolocation, Device IDs, Contacts, Financial info, Biometrics, or Activity Logs.
  • Four-Stage Lifecycle Classifier: Evaluates every clause against the 4 lifecycle steps: Collect, Use, Share, and Keep.
  • Quote Verifier: Verifies that every extracted quote exists verbatim in the raw input text.
  • Hedge & Vagueness Detector: Highlights language that expands corporate discretion without explicit boundaries.

Tech Stack

  • Vite 6 + React 19 + TypeScript: Fast bundling, strict typing, responsive state management.
  • Tailwind CSS: Obsidian dark theme, customizable utility classes.
  • Lucide React: Consistent, modern iconography for privacy indicators and navigation.
  • Vitest: Unit testing for deterministic clause parsing and quote validation.

Data Model Schema

export type HonestyStatus = 'stated' | 'vague' | 'not_found' | 'interpreted';
export type StageName = 'collect' | 'use' | 'share' | 'keep';

export interface VerbatimEvidence {
  quote: string;
  sourceSection?: string;
  hedgesFound?: string[];
  lineNumber?: number;
}

export interface TrailStage {
  stage: StageName;
  title: string;
  status: HonestyStatus;
  headline: string;
  summary: string;
  evidence: VerbatimEvidence[];
  vaguenessReason?: string;
}

export interface DataTypeTrail {
  id: string;
  label: string;
  iconName: string;
  description: string;
  stages: Record<StageName, TrailStage>;
  necessityNote: {
    coreUtilityRelation: string;
    proportionalityAssessment: string;
    status: 'proportional' | 'excessive_scope' | 'vague_justification';
  };
}
