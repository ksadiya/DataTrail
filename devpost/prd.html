DataTrail — Product Requirements

An interactive privacy-intelligence web application that turns real privacy policies into an evidence-backed personal data journey: COLLECT → USE → SHARE → KEEP.

System Journey & Data Movement Architecture

The Core User Journey

  1. Arrival & Policy Choice: User accesses the application and picks a real India-relevant sample (Swiggy, Zomato, WhatsApp), pastes their own custom policy, or uploads a document.
  2. Automated Analysis: The deterministic policy analyzer engine scans the text, categorizes clauses, and surfaces detected data types (e.g. Precise Location, Contact List, Biometrics, Device IDs).
  3. Category Selection: User selects one data type to inspect its individual data lifecycle.
  4. Interactive 4-Stage Trail: Inspects the four stages (Collect → Use → Share → Keep), viewing verbatim policy quotes and honest confidence ratings.
  5. Evidence Deep Dive: Clicks into any stage to open the side inspector, highlighting ambiguous hedges and exact policy sentences.
  6. Necessity & Rights: Reads the interpreted necessity evaluation and checks stated grievance officer / opt-out contact information.
The Core Test: When a user switches policies or data types, the entire trail updates dynamically with verified verbatim quotes from that exact policy. No hardcoded mockups.

Honesty Classification Schema

DataTrail separates direct legal claims from inferences and highlights omission:

  • STATED Direct Claim: The policy explicitly states this action with unambiguous language and verbatim quotations.
  • VAGUE Ambiguous Clause: The policy uses legal qualifiers like "including but not limited to", "may share with partners", or "for internal enhancements" without specific boundaries.
  • NOT FOUND Omission / Silence: The policy completely fails to disclose information for this stage (e.g. no retention schedule or no listed third parties).
  • INTERPRETED Analytical Assessment: Evaluates functional necessity vs. broad data harvesting. Clearly marked as non-policy interpretation.

Key Features & Proof of Concept Slices

1. Multi-Input Policy Ingestion

Supports real pre-loaded policies, raw clipboard paste, plain text file upload, and URL fetching with honest error boundaries.

2. Dynamic Data Category Discovery

Extracts personal data mentions directly from the uploaded text rather than forcing a pre-configured template.

3. Verbatim Evidence Drawer

Displays the exact sentences from the policy with zero generative hallucinations.

4. Rights & Contact Extractor

Extracts Grievance Officer contacts, DPO email addresses, and deletion instructions.

States and Boundaries

  • Empty Input State: Clear visual prompts explaining how to choose a sample or paste text.
  • Short / Invalid Text: Helpful alert if input text has fewer than 50 words or lacks privacy clauses.
  • URL Fetch Fallback: When client-side cross-origin fetch is blocked by CORS or paywalls, DataTrail honestly reports the network block and provides an instant 1-click paste fallback.
  • Runtime Honesty: Clear disclaimer that DataTrail analyzes legal representations, not real-time network traffic.

Consequential Product Decisions

  • No aggregate score: A score hides evidence and provides false security. DataTrail provides granular transparency.
  • No chatbot: A conversational agent buries findings. The 4-stage map provides immediate structural understanding.
  • Deterministic extraction: Built on grounded NLP sentence matching to prevent quote fabrication.
